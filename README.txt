VIENSCO DOCS – flat version (all files in one folder, no sub-folders)

Upload ALL files in this folder to a free HTTPS host (GitHub Pages, Netlify Drop, Cloudflare Pages).
Open the link in Chrome on the phone -> Install app / Add to Home screen. After the first open it works offline.
To update later, change the files and bump CACHE in sw.js (viensco-docs-v1 -> v2).
Your data lives in the phone's browser storage: use Settings > Backup regularly.
